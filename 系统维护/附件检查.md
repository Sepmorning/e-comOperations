# 🖼️ 附件引用检查

> [!info] 先看引用，再清理
> 此页只读取并列出图片，不自动删除或移动。移除正文中的图片链接不会删除图片文件。当前附件位置为笔记所在目录的 `assets` 子目录。
>
> 新截图建议命名为“笔记名-时间戳”。删除候选仍需预览核实：文件可能用于仓库外的文档，或藏在压缩绘图数据中。下面的文本扫描采用保守匹配，宁可多保留。

```dataviewjs
const images = app.vault.getFiles().filter(f => /^(png|jpe?g|gif|webp|svg|bmp|avif)$/i.test(f.extension));
const sources = app.vault.getFiles().filter(f => /^(md|canvas|json|base|html|css|excalidraw)$/i.test(f.extension) && f.path !== dv.current().file.path);
const texts = await Promise.all(sources.map(async f => {
  try { const raw = await app.vault.cachedRead(f); let decoded=raw; try { decoded=decodeURIComponent(raw); } catch {} return { f, raw: (raw+'\n'+decoded).toLowerCase() }; }
  catch { return {f, raw:null}; }
}));
const unread = texts.filter(x=>x.raw===null);
const compressed = texts.filter(x=>x.raw?.includes('```compressed-json')).length;
const refs = images.map(img => {
  const linked = texts.filter(({f,raw}) => raw?.includes(img.name.toLowerCase()) || app.metadataCache.resolvedLinks[f.path]?.[img.path]);
  return {img, linked};
});
const maybe = refs.filter(x=>!x.linked.length);
dv.paragraph(`📦 图片 **${images.length}** 张 · 有引用或同名文本匹配 **${refs.length-maybe.length}** 张 · 待核查 **${maybe.length}** 张`);
if (unread.length || compressed) dv.paragraph(`⚠️ 有 ${unread.length} 个文件读取失败、${compressed} 个文件含压缩绘图数据；“待核查”不能作为安全删除结论。`);
dv.header(2,'🟠 待核查图片');
dv.table(['图片（点击预览）','目录','大小 KB'], maybe.map(({img})=>[dv.fileLink(img.path),img.parent.path,Math.round(img.stat.size/1024)]));
dv.header(2,'🔗 已引用 / 文本匹配');
dv.table(['图片','来源笔记或文件'], refs.filter(x=>x.linked.length).map(({img,linked})=>[dv.fileLink(img.path),linked.map(x=>dv.fileLink(x.f.path))]));
```

## 🧹 每月清理一次

1. 打开此页，查看“待核查图片”。
2. 点击预览，确认不是临时素材、外部文档或绘图要用的图片。
3. 在 Obsidian 文件列表中定位该图片，再决定是否删除。保留删除确认，使用 Obsidian 回收站便于恢复。
4. 已引用列表会显示来源笔记；修改图片名请在 Obsidian 内进行，保证内部链接跟随更新。

> [!tip] 查看最新结果
> 关闭后重新打开此页，或执行 Dataview 的刷新视图命令。不要把审计结果复制成图片链接清单，否则清单本身也会成为引用。
