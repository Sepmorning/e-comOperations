# 领星ERP｜透明计划标签申请与打印 SOP

> [!summary] SOP目的
> 在领星ERP中为指定 ASIN 申请 Amazon Transparency **T-Code**，导出透明计划标签 PDF，并发送给仓库打印、贴标；同时查询历史申请记录及已使用/未使用数量。

## 一、适用范围

适用于已加入 Amazon Transparency（透明计划）、需要通过领星ERP购买并打印透明计划标签的商品。

## 二、操作前准备

- 已登录正确的领星ERP账号及店铺。
- 商品已同步至领星的「透明计划」模块。
- 已准备需要申请标签的 **ASIN**。
- 已确认本次实际需要的标签数量。
- 已确认账户余额或扣费账户正常。

> [!danger] 费用提醒
> 提交 T-Code 申请后会直接产生费用并扣款，等同于直接购买标签。提交前必须再次核对 **ASIN、商品和申请数量**，避免重复申请或数量填错。

## 三、流程概览

```text
产品 → 透明计划 → 商品列表/全部
→ 搜索 ASIN → 勾选目标商品
→ 申请 T-Code → 输入申请数量 → 提交并扣费
→ 查看 T-Code 数及括号内未使用数量
→ 勾选商品 → 打印透明计划标签
→ 导出 PDF → 下载并发送仓库
```

## 四、详细操作步骤

### 步骤 1：进入「透明计划」

1. 登录领星ERP。
2. 在左侧导航栏进入 **产品**。
3. 在产品管理菜单中点击 **透明计划**。
4. 默认进入顶部的 **商品列表** 页面，并选择 **全部**。

![[assets/01-进入透明计划.png]]

---

### 步骤 2：按 ASIN 查找商品

1. 在搜索条件中选择 **ASIN**。
2. 输入需要申请透明计划标签的 ASIN。
3. 点击搜索图标或按回车查询。
4. 核对查询结果中的商品信息，包括：
   - ASIN
   - 标题
   - SKU/品名
   - 透明计划账号
   - 标签类型
   - T-Code 数量

![[assets/02-搜索ASIN并查看T-Code数量.png]]

> [!info] T-Code 数量的读取方式
> 页面字段通常显示为 **T-Code数（未使用）**。例如 `1260(0)` 表示累计/当前显示的 T-Code 数为 1260，括号内未使用数量为 0。打印前应重点确认括号内的未使用数量是否足够。

---

### 步骤 3：勾选商品并申请 T-Code

1. 勾选目标商品左侧的复选框。
2. 点击页面上方的 **申请T-Code**；也可使用商品行右侧的 **申请T-Code** 操作入口。
3. 在弹出的「申请T-Code」窗口中，确认 ASIN/GTIN、商品标题及透明计划账号无误。
4. 在 **申请数量** 中填写本次需要购买的标签数量。
5. 点击右下角 **提交**。

![[assets/03-填写T-Code申请数量.png]]

> [!warning] 提交前必查
> - 商品/ASIN 是否正确。
> - 申请数量是否与本次生产或发货需求一致。
> - 是否已经申请过同一批次，避免重复购买。
> - 页面提示单个商品单次申请数量上限为 10 万个；大批量申请时可根据页面规则拆分。

> [!danger] 提交后立即扣费
> 点击「提交」并申请成功后，系统会直接扣费。该操作不是询价，也不是预占数量。

---

### 步骤 4：确认申请结果及未使用数量

1. 申请完成后返回商品列表。
2. 必要时刷新页面。
3. 在 **T-Code数（未使用）** 一栏确认数量已经更新。
4. 括号中的数字为当前未使用数量，应不小于本次需要打印的标签数量。

> [!tip] 数量核对建议
> 建议记录：ASIN、申请日期、申请数量、扣费金额或订单凭证、操作人，以便后续对账和追踪。

---

### 步骤 5：打印透明计划标签并导出 PDF

1. 勾选需要打印标签的商品。
2. 点击页面上方 **打印透明计划标签**。
3. 在打印设置页面选择所需标签数量及对应打印范围。
4. 选择 **导出为 PDF**。
5. 下载 PDF，并打开抽查：
   - PDF 能正常打开；
   - 标签数量与需求一致；
   - 标签内容清晰、无空白页或缺失；
   - 对应 ASIN/商品无误。
6. 将 PDF 发送给仓库，要求仓库按对应商品打印并贴标。

![[assets/04-勾选商品并打印透明计划标签.png]]

> [!warning] 仓库交接
> 同一份 PDF 可能包含多个唯一 T-Code。不要重复打印、重复使用或将不同商品的标签混用。仓库打印参数应按实际标签纸规格执行，并确保条码清晰可扫描。

## 五、查看历史 T-Code 申请记录

1. 进入 **产品 → 透明计划**。
2. 点击页面顶部的 **T-Code列表**。
3. 可查询所有历史申请过的透明计划标签记录。
4. 重点查看：
   - 申请时间；
   - ASIN/商品；
   - 申请数量；
   - 已使用数量；
   - 未使用数量；
   - 相关批次或状态。

> [!note] 使用场景
> 「T-Code列表」适合用于历史追溯、库存盘点、重复申请排查及月度费用对账。

## 六、推荐的文件命名与归档

建议下载后按以下规则重命名：

```text
T-Code_ASIN_数量_申请日期.pdf
```

示例：

```text
T-Code_B09X56M24N_1260_20260717.pdf
```

建议归档目录：

```text
透明计划标签/
├── 2026-07/
│   ├── Transparency_B09X56M24N_1260_20260717.pdf
│   └── 申请记录.xlsx
└── 历史记录/
```

## 七、异常处理

| 异常情况          | 处理方法                                             |
| ------------- | ------------------------------------------------ |
| 搜索不到 ASIN     | 检查 ASIN 是否输入正确；确认商品是否已同步到透明计划；尝试点击「同步商品」后重新查询。   |
| 申请按钮不可用       | 检查是否已勾选商品、账号权限、透明计划账号配置及商品状态。                    |
| 提交后数量未更新      | 刷新页面并等待短时间后重试；到 T-Code列表核对是否已有申请记录，避免再次提交造成重复扣费。 |
| 未使用数量不足       | 先确认是否有其他待打印/已导出批次占用；确实不足时再申请新的 T-Code。           |
| PDF 无法打开或标签缺失 | 重新导出；核对导出范围、数量及浏览器下载状态。                          |
| 仓库反馈无法扫描      | 重新导出原始 PDF，避免截图打印；检查打印清晰度、缩放比例和标签纸规格。            |
