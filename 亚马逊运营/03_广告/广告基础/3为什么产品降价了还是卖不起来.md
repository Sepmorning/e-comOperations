# 为什么产品降价了还是卖不起来？

> [!summary] 核心结论
> **价格只是成交系统中的一个变量。** 降价主要影响点击意愿、购买转化和利润，但不能自动创造需求、精准流量、信任或差异化。
>
> 可以把订单粗略拆成：
>
> $$\text{订单量} \approx \text{曝光量} \times \text{点击率（CTR）} \times \text{转化率（CVR）}$$
>
> 如果问题发生在曝光、流量精准度、产品需求、页面说服力或履约体验上，单独降价通常难以解决。

## 一、先判断问题发生在哪一层   

| 漏斗阶段         | 常见表现      | 优先检查                        | 不应先做什么      |
| ------------ | --------- | --------------------------- | ----------- |
| 曝光不足         | 广告与自然曝光都少 | 收录、关键词相关性、广告状态、库存、类目、配送资格   | 直接大幅降价      |
| 有曝光、少点击      | CTR低      | 主图、标题、价格展示、评分、评论数、配送时效、促销标识 | 同时改主图、标题和价格 |
| 有点击、少下单      | CVR低      | 页面卖点、变体、评论、价格、竞品差距、退货顾虑、适配性 | 只提高广告预算     |
| 订单增加、利润下降    | 销量对折扣高度敏感 | 毛利、广告费、退货成本、折扣侵蚀、自然单占比      | 用销售额代替利润判断  |
| 流量和转化都正常但规模小 | 市场容量有限    | 搜索需求、季节性、地区适配、使用场景          | 把小市场误判为运营失败 |

> [!tip] 推荐排查顺序
> **先曝光 → 再点击 → 再转化 → 最后看利润。** 每次只改一个主要变量，否则无法判断究竟是哪项改动产生作用。

---

## 二、原因一：流量不足或流量不精准

### 1. 曝光不足

降价不会让一个几乎没有曝光的商品自动被看见。应先确认：

- ASIN是否被核心关键词正常收录；
- 自然搜索与广告是否获得有效展示；
- 广告是否因预算、竞价、相关性或投放设置而无法展示；
- 商品是否缺货、配送时效过长或失去购买按钮区域中的竞争资格；
- 类目、属性和后台搜索词是否准确。

品牌备案卖家可重点使用：

- **Search Query Performance**：查看搜索词带来的曝光、点击、加购和购买；
- **Search Catalog Performance**：观察ASIN在搜索漏斗中的整体表现；
- **Product Opportunity Explorer**：研究需求趋势、搜索行为与细分机会。

### 2. 流量不精准

宽泛关键词可能带来大量“看过但不需要”的访客。例如，针对特定功能收纳柜，却主要投放“home decor”一类泛词，即使点击量增加，也未必产生购买。

广告优化应关注：

- 搜索词是否符合实际使用场景；
- 广泛、词组、精准匹配的流量质量差异；
- 搜索词报告中的花费、订单、CVR和ACoS；
- 与产品不匹配的词是否需要否定；
- 自动投放发现的新词是否应转入手动精准投放。

## 三、原因二：竞争壁垒过高

强品牌、高评论、高履约水平的类目，对新链接的主要挑战不是“价格不够低”，而是**信任成本和获客成本过高**。

### 竞争壁垒的真实表现

- 头部点击和销量长期集中于少数品牌或ASIN；
- 竞品拥有显著的评论数量、评分、品牌认知和配送优势；
- 核心大词CPC较高，新品获取一次有效订单的成本超过可承受范围；
- 产品高度同质化，消费者只能以价格和评论做决策；
- 即使低价引流，页面转化仍明显落后于头部竞品。

### 不要只看“首页有多少自然位”

搜索结果页中的自然结果、广告位和其他展示模块会变化，**自然位数量本身不能证明某个类目一定是“红海”**。更可靠的判断指标包括：

1. 核心搜索词的需求规模和趋势；
2. 点击份额是否集中于少数品牌或ASIN；
3. 前排竞品的价格、评分、评论数与配送差距；
4. CPC、转化率和盈亏平衡ACoS；
5. 新品能否通过细分场景获得更高的相关性和CVR。

### 可行策略

- 避开与强势品牌完全相同的大词和通用品；
- 从长尾词、特定人群、尺寸、环境或任务场景切入；
- 让差异化成为消费者可立即理解的购买理由；
- 先在小规模精准需求中建立评价、转化和复购，再扩大词路。

## 四、原因三：价值没有被有效传递

### 1. 只写功能，没有说明结果

消费者既需要参数，也需要知道参数对自己有什么意义。

| 低效表达 | 更好的表达逻辑 |
|---|---|
| 铝合金、360°旋转、承重500 g | 说明适用设备、使用位置、稳定性以及解决的具体麻烦 |
| PP材质，30 × 20 × 15 cm，带盖 | 说明能收纳什么、占用多少空间、如何快速取放 |
| 进口网面办公椅 | 说明透气、支撑、调节方式和适合的工作时长，但避免无法证明的健康承诺 |

好的页面应回答：

- 它解决谁的什么问题？
- 在什么场景中使用？
- 相比替代方案有什么可验证的优势？
- 用户购买后会获得什么具体、可信的改善？

### 2. 差异化无法被感知

差异化不一定是颠覆式创新，也可以是可验证的小优势：

- 耐久测试结果；
- 单手操作；
- 更明确的适配范围；
- 更方便的查找或收纳结构；
- 更稳定的特定场景表现；
- 更清晰的安装、售后或使用指导。

> [!warning] 合规提醒
> “腰背救星”“8小时不酸痛”“绝对防抖”等表达可能构成无法证实、误导性或健康效果声明。产品页面、图片、包装和广告中的声明都应有证据支持，并符合所在站点及品类规则。

### 3. 价格锚点被破坏

频繁、长期或无明确逻辑的降价可能带来：

- 消费者等待下一次更低价格；
- 原价可信度下降；
- 折扣失去稀缺性；
- 参考价和促销展示受到历史成交价影响；
- 低价订单增加，但利润和客户质量下降。

因此，降价前应明确目标：清库存、拉新、验证价格弹性、提高转化，还是参加促销。不同目标需要不同幅度、时长和复盘指标。

## 五、原因四：用户需求与使用场景不匹配

### 1. 需求过于模糊

“手机壳”代表的意图很宽泛；“适合户外工作、防摔、兼容某机型的手机壳”代表的购买意图更明确。流量越宽泛，价格敏感型点击通常越多，但不一定产生有效订单。

### 2. 卖点没有激活真实需求

不要只用情绪化语言制造焦虑，而应把问题、场景、产品机制和证据连接起来：

> 用户问题 → 使用场景 → 产品设计 → 可验证结果

例如办公椅可以说明腰托结构、调节范围、坐垫尺寸和适用身高，而不是直接承诺“坐8小时不酸痛”。

### 3. 时机或市场错位

季节性不能只按月份判断。八月的羽绒服在北半球多数市场可能处于淡季，但在南半球、寒冷地区或提前备货人群中未必如此。应依据具体站点的搜索趋势、天气、节日和历史订单判断。

## 六、原文中需要更正或弱化的知识点

| 原观点                        | 更正后的理解                                                        |
| -------------------------- | ------------------------------------------------------------- |
| 首页拥有100%曝光能力，第二页30%，第三页15% | 未找到亚马逊官方发布的固定比例。曝光受搜索词、广告、设备、位置、个性化和时间影响，应以账户实际曝光、点击和购买数据判断。  |
| 首页有16个自然位，说明是血海品类          | 自然位数量不是竞争强度指标。应结合点击集中度、CPC、评论壁垒、品牌集中度和盈亏模型。                   |
| 没有销量和转化，亚马逊就不会给流量          | 这是过度简化。搜索相关性、Listing质量、价格、履约、账户健康和广告都可能影响可见度；平台没有公布如此简单的单一公式。 |
| 单纯降价不会带来更多曝光               | 不能绝对化。亚马逊官方资料将价格调整列为可能改善排名和销量的手段之一，但其效果取决于相关流量、竞争力和利润空间。      |
| 降价会立即触发原价订单退货              | 这是可能发生的消费者行为，不是平台必然机制。应查看实际退货原因、下单时间和退货率变化后再判断。               |
| 频繁降价只影响消费者心理锚点             | 还会影响参考价与促销展示。2026年亚马逊已更新List Price和Typical Price的验证与计算要求。     |
| “8小时不酸痛”等语言可以激活痛点          | 可能存在误导或声明无法证实的风险。应改为可验证的结构、测试、适配和使用信息。                        |
| 八月促销羽绒服一定无效                | 取决于站点、地区、季节、天气和购物周期，不能跨市场一概而论。                                |

## 七、2026年需要特别注意的参考价更新

> [!important] 规则更新
> 原文发布于2026年2月。此后亚马逊对参考价进行了更新：
>
> - **自2026年4月23日起**，卖家提供的List Price需满足近期在其他零售商处以该价格销售，或在亚马逊以Featured Offer价格被购买等验证条件；
> - **自2026年5月18日起**，Typical Price仍以过去90天客户支付的非促销价格中位数为基础；若90天价格历史中超过一半的天数低于非促销中位数，计算时可能纳入全部销售，包括促销销售；未作为促销展示的降价会被视为非促销销售并计入Typical Price。
>
> 因此，长期直接下调售价可能不仅影响消费者预期，也可能改变后续参考价和折扣展示基础。

## 八、可执行的诊断与测试方案

### 第一步：建立基线

至少记录调整前7–14天数据：

- 曝光量；
- CTR；
- Sessions或详情页访问量；
- CVR；
- 广告花费、CPC、ACoS；
- 总销售额、广告销售额、自然销售额；
- 退款率、退货原因；
- 单件贡献毛利。

### 第二步：计算底线

$$\text{单件贡献毛利} = \text{售价} - \text{采购成本} - \text{平台费用} - \text{履约与物流} - \text{折扣} - \text{退货预提}$$

$$\text{盈亏平衡ACoS} = \frac{\text{广告前贡献毛利}}{\text{销售额}}$$

任何折扣都应先确认不会把实际ACoS推到盈亏平衡线以上。

### 第三步：一次只测试一个核心变量

- **曝光问题**：先改收录、关键词或广告投放；
- **点击问题**：优先测试主图、标题、价格展示或促销标识；
- **转化问题**：测试卖点、图片、A+、价格、变体或配送体验；
- **利润问题**：减少无效词、调整竞价、优化价格带和成本。

品牌备案卖家可使用Manage Your Experiments对标题、图片、描述或A+内容做A/B测试。价格测试通常需要分时段控制，且要尽量保持广告、库存和页面内容不变。

### 第四步：判断降价是否有效

降价后至少同时观察：

- CTR是否提高；
- CVR是否提高；
- 订单增量能否覆盖单件毛利损失；
- 广告效率是否改善；
- 自然单占比是否变化；
- 退货率与评价质量是否恶化；
- 促销结束后销量是否快速回落。

> [!example] 简化判断
> - **曝光不变、CTR上升、CVR上升、利润上升**：价格可能原本偏高；
> - **曝光不变、CTR上升、CVR不变**：价格能吸引点击，但页面或产品承接不足；
> - **曝光和CTR都不变**：问题大概率不在价格；
> - **订单增加但利润下降**：折扣换销量失败；
> - **促销结束即归零**：需求可能高度依赖低价，尚未形成稳定竞争力。

## 九、一句话总结

> **降价是一种放大器，不是发动机。** 当流量精准、产品有需求、页面能传达价值、信任与履约过关时，价格才可能成为有效杠杆；否则降价只是把原有问题以更低利润继续放大。
